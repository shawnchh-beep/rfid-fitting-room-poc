# 🎨 RFID Fitting Room Dashboard 配色規格書 v3.2

## 1. 設計目標

本配色系統旨在達成以下目標：

- 提升 Dashboard **資訊辨識效率**
- 強化「試穿 → 購買」的**商業轉換感**
- 建立 **零售 + 科技 + 即時數據** 的視覺風格
- 避免傳統企業系統的沉悶灰藍風格

---

## 2. 色彩策略總覽

| 類型        | 目的                     | 設計方向              |
|------------|--------------------------|-----------------------|
| Primary    | 品牌與操作焦點           | 科技感藍紫            |
| Success    | 成交 / 正向結果          | 綠色                  |
| Hot        | 熱度 / 高關注            | 偏粉紅紅（時尚感）     |
| Warning    | 警示 / 異常              | 橘黃色                |
| Neutral    | 背景 / 結構              | 淺灰白                |

---

## 3. 核心配色定義

### 🎯 Primary（主色）
```css
--color-primary: #5B6CFF;
--color-primary-hover: #4454E6;
--color-primary-light: #EEF1FF;
````

用途：

* 主要按鈕（CTA）
* Active 狀態（選單 / Tab）
* AI 操作入口

---

### 🟢 Success（成功 / 轉換）

```css
--color-success: #22C55E;
--color-success-light: #DCFCE7;
```

用途：

* Sales / Completed
* Conversion Rate ↑
* 成功狀態提示

---

### 🔴 Hot（熱度 / 試穿）

```css
--color-hot: #F43F5E;
--color-hot-light: #FFE4E6;
```

用途：

* Try-on 次數高
* 熱門商品
* Opportunity 指標

---

### 🟡 Warning（警示）

```css
--color-warning: #F59E0B;
--color-warning-light: #FEF3C7;
```

用途：

* Abnormal Stay
* Alert / Risk
* 庫存異常

---

### ⚪ Neutral（中性 / 結構）

```css
--color-bg-main: #F8FAFC;
--color-bg-card: #FFFFFF;
--color-bg-section: #F1F5F9;

--color-text-primary: #0F172A;
--color-text-secondary: #64748B;
--color-border: #E2E8F0;
```

用途：

* 頁面背景
* 卡片區塊
* 文字與分隔

---

## 4. UI 元件配色規範

### 4.1 KPI 卡片

#### 設計規則：

* 使用「左側色條」或「Top Border」區分指標類型
* 不可全部同色（避免資訊失焦）

#### 對應規則：

| KPI 類型            | 顏色         |
| ----------------- | ---------- |
| Try-On Sessions   | 🔴 Hot     |
| Conversion Rate   | 🟢 Success |
| Alerts / Abnormal | 🟡 Warning |
| AI Status         | 🔵 Primary |

---

### 4.2 Funnel（轉換流程）

#### 色彩流：

```
Try-On → Checkout → Sales

🔴 → 🟡 → 🟢
```

#### 規則：

* 使用漸層或顏色遞進
* 不可全部使用單一顏色

---

### 4.3 商品卡（Opportunity / Rack）

#### 規則：

* 左側色條表示「熱度」
* Badge 顯示轉換率

| 狀態     | 顏色         |
| ------ | ---------- |
| 高試穿低轉換 | 🔴 Hot     |
| 高轉換    | 🟢 Success |
| 普通     | ⚪ Neutral  |

---

### 4.4 按鈕（Buttons）

#### Primary Button

```css
background: var(--color-primary);
color: #FFFFFF;
```

#### Secondary Button

```css
background: #FFFFFF;
border: 1px solid var(--color-border);
color: var(--color-text-primary);
```

---

### 4.5 AI 區塊（特殊模組）

```css
background: #F5F3FF;
border: 1px solid #C4B5FD;
```

設計原則：

* 必須與一般卡片區隔
* 強調「智慧決策來源」

---

### 4.6 即時狀態（Live Status）

| 狀態     | 顏色      |
| ------ | ------- |
| Quiet  | #94A3B8 |
| Normal | #3B82F6 |
| Busy   | #EF4444 |

規則：

* 必須搭配圓點 indicator
* 不可只用文字

---

## 5. 使用原則（重要）

### ✔ Do

* 用顏色建立「資訊優先順序」
* 高價值資訊使用高對比色
* 保持整體色彩數量控制（不超過 6 種主色）

---

### ❌ Don’t

* 所有卡片同色（會失去決策價值）
* 過度使用灰色（降低活力）
* 用紅色表示所有狀態（會失去語意）

---

## 6. 設計結論

本配色系統核心原則：

> **顏色不是裝飾，而是決策工具**

透過「紅（熱度）→ 黃（過程）→ 綠（轉換）」的視覺語言，
讓使用者在 3 秒內理解：

* 哪些商品熱門但沒轉單
* 哪些機會需要立即處理
* 哪裡正在產生營收
