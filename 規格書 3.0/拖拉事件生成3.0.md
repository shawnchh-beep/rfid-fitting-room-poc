

請建立一個新的 Fitting Room Demo 頁面，作為 RFID demo 的核心流程操作頁。
這個頁面的目標不是資料維護，而是讓使用者透過 drag and drop 方式模擬商品從貨架、進試衣間、回貨架、到結帳的流程。

請保留整體風格為 clean, professional, enterprise SaaS dashboard，不要做成遊戲介面，也不要做成過度花俏的動畫展示頁。

⸻

開發目標

建立一個 三欄式拖拉互動頁面，支援以下 4 條合法拖拉路徑：
	1.	Rack -> Fitting Room
	2.	Fitting Room -> Rack
	3.	Fitting Room -> Checkout
	4.	Rack -> Checkout

並且每次拖拉成功都要：
	•	更新資料狀態
	•	觸發對應事件
	•	刷新 UI
	•	顯示成功或失敗提示

⸻

拖拉規則

請只允許以下合法路徑：

合法
	•	Rack -> Room
	•	Room -> Rack
	•	Room -> Checkout
	•	Rack -> Checkout

非法
	•	Rack -> Rack
	•	Checkout -> Rack
	•	Checkout -> Room
	•	Room -> Room

非法拖拉時：
	•	item 回彈原位
	•	顯示 toast：Invalid move

⸻

拖拉成功後的事件邏輯

1. Rack -> Room

成功 drop 後：
	•	create event: enter_room
	•	create fitting session
	•	item status = in_room
	•	record entered_at
	•	assign room_id

⸻

2. Room -> Rack

成功 drop 後：
	•	create event: exit_room
	•	update fitting session
	•	set exited_at
	•	calculate dwell_seconds
	•	set session status = exited
	•	item status = on_floor

⸻

3. Room -> Checkout

成功 drop 後：
	•	create event: exit_room
	•	create event: sale_completed
	•	update fitting session
	•	set exited_at
	•	calculate dwell_seconds
	•	set is_converted = true
	•	create sale record
	•	item status = sold
	•	sale type = try_on_purchase

⸻

4. Rack -> Checkout

成功 drop 後：
	•	create event: direct_sale
	•	create sale record
	•	do NOT create fitting session
	•	item status = sold
	•	sale type = direct_purchase

注意：
	•	direct purchase 不納入 try-on conversion

⸻

UI 互動規格

拖曳開始
	•	dragged card 顯示 dragging 狀態
	•	合法 drop zones 高亮
	•	不合法區域不高亮

拖曳中
	•	顯示 drag preview / ghost
	•	hovered valid zone 顯示 active border or soft highlight

成功放下
	•	執行事件更新
	•	完成後刷新 UI
	•	顯示對應 toast

success toast 建議
	•	Item entered fitting room
	•	Item returned to rack
	•	Purchase completed
	•	Direct purchase completed

放下失敗
	•	回彈
	•	顯示 toast：
	•	Invalid move
	•	Action could not be completed
